Rerunning it

Rerunning it

Requires Eclipse SUMO 1.27.1 and Python 3. Put the scripts beside the networks and demand, then:

export SUMO_HOME=/path/to/sumo
python3 gen_demand.py        # build the demand set
python3 build_nets.py        # build the network variants
python3 run_batch.py         # run every variant, both demand levels
python3 measure_current.py   # measure the current system per approach
python3 build_casestudy.py   # regenerate the page

All 64 data files and the full run set complete in a few minutes on a laptop.
